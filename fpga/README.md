# FPGA Build — Cora Z7-07S

Build and run the systolic array on the Digilent Cora Z7-07S (XC7Z007S-1CLG400C).

## Board Summary

| Property | Value |
|----------|-------|
| Part | XC7Z007S-1CLG400C |
| PL clock | 125 MHz (FCLK_CLK0 from Zynq PS) |
| DSP slices | 66 |
| LUTs | 14,400 |
| Master XDC | [Digilent Cora-Z7-07S-Master.xdc](https://github.com/Digilent/digilent-xdc/blob/master/Cora-Z7-07S-Master.xdc) |

## Prerequisites

- Vivado 2022.1 or later (with Zynq-7000 support)
- Cora Z7-07S board with USB-JTAG cable
- Python 3.10+ with numpy (for host demo)

## Build Steps

### 1. Create Vivado Project

```bash
vivado -mode batch -source scripts/run_synth.tcl
```

This will:
1. Create a project targeting `xc7z007sclg400-1`
2. Add all RTL sources and constraints
3. Run synthesis and implementation
4. Write a bitstream to `fpga/project/`
5. Print utilization (LUTs, FFs, DSP48s, BRAM, Fmax)

### 2. Inspect Utilization Report

After synthesis, check the report for:

| Resource | What to look for |
|----------|-----------------|
| DSP48E1 | 16 PEs × 1 multiply each = ~16 DSPs |
| LUTs | Control logic + routing |
| FFs | Pipeline registers in PEs |
| Fmax | Should exceed 125 MHz target |

This connects algorithm → numeric representation → hardware resources.

### 3. Program the Board

Open the generated bitstream in Vivado Hardware Manager, or:

```bash
vivado -mode batch -source fpga/program.tcl
```

(Program script is generated by `run_synth.tcl`.)

## AXI Register Map

The `axi_wrapper` module exposes these registers to the Zynq PS:

| Offset | Name | Access | Description |
|--------|------|--------|-------------|
| 0x00 | CTRL | W | Write 1 to start computation |
| 0x04 | STATUS | R | Bit 0 = done flag |
| 0x10–0x4C | A_MEM[16] | W | Matrix A (int8, row-major) |
| 0x50–0x8C | B_MEM[16] | W | Matrix B (int8, row-major) |
| 0x90–0xCC | C_MEM[16] | R | Matrix C (int32, row-major) |

## Block Design

The Zynq block design (`fpga/block_design.tcl`) connects:

```text
Zynq PS ── AXI GP0 ── axi_wrapper ── top ── systolic_array_4x4
```

- PS runs Linux (Petalinux or Pynq)
- PL runs the systolic array at 125 MHz
- Host Python script reads/writes AXI registers via `/dev/mem` or a UIO driver

## LEDs

| LED | Meaning |
|-----|---------|
| Green (led_g) | PASS — FPGA result matches golden model |
| Red (led_r) | FAIL — mismatch detected |
| Blue (led_b) | Busy — computation in progress |

## Timing Notes

The accumulator path in each PE uses a DSP48 for int8×int8 multiply. A multicycle constraint is applied in `constraints.xdc` because the accumulate feedback path may need 2 cycles at 125 MHz. See the constraint file comments for details.

## Troubleshooting

| Problem | Solution |
|---------|----------|
| Synthesis fails on array ports | Ensure unpacked array ports are supported; check Vivado version |
| Fmax < 125 MHz | Review multicycle constraints; reduce clock frequency |
| Wrong matrix result | Verify register map byte order matches host script |
| `demo_host.py` exits immediately | Use `--simulate` for software-only testing |
